
# ONLINE RETAIL DATA ANALYTICS PROJECT
End-to-end Online Retail Data Analytics project using Excel, SQL, Python, and Power BI for data cleaning, analysis, visualization, and business insights.



## Features

- Data Cleaning and Preprocessing using Excel and Python
- Data Analysis using SQL
- Exploratory Data Analysis using Python
- Interactive Dashboard using Power BI
- Sales and Customer Analysis
- Monthly Sales Trend Analysis
- Country-wise Sales Analysis
- Business Insights and Recommendations


## Installation

Installation

1. Clone the repository
2. Open the Excel dataset for data cleaning
3. Import the cleaned dataset into MySQL for SQL analysis
4. Run the Python analysis using Jupyter Notebook
5. Open the Power BI file to view the interactive dashboard
    
##  Tools Used

- Microsoft Excel – Data Cleaning
- MySQL – Data Analysis
- Python – Data Manipulation and Analysis
- Pandas – Data Processing
- Matplotlib – Data Visualization
- Power BI – Interactive Dashboard
- GitHub – Project Documentation
##  Dataset

The dataset contains online retail transaction information including:

- Invoice Number
- Stock Code
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country
## project workflow

### 1. Data Cleaning – Excel

- Removed duplicate records
- Handled missing values
- Cleaned product descriptions
- Checked data types
- Identified invalid values

### 2. Data Analysis – SQL

SQL was used to analyze:

- Total Sales
- Total Orders
- Top Selling Products
- Country-wise Sales
- Customer Analysis

### 3. Data Analysis – Python

Python and Pandas were used for:

- Data loading
- Data exploration
- Statistical analysis
- Data manipulation
- Finding sales trends

### 4. Data Visualization – Power BI

An interactive dashboard was created to visualize:

- Total Sales
- Total Orders
- Sales by Country
- Monthly Sales Trends
- Top Products
- Key Business Insights

## key insights

- Identified top-performing products
- Analyzed monthly sales trends
- Compared sales across different countries
- Identified customer purchasing patterns
- Analyzed overall retail business performance

The Power BI dashboard provides an interactive overview of retail sales performance and key business metrics.
